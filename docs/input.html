Log time

Shadow-player time logs itself. Everything external is two fields - the Dreaming Spanish rule: if logging takes effort, it stops happening.

Pre-input comprehension

Before any native video or podcast: get the transcript, read it, learn the new words, then watch. This moves you from ~10% comprehension (noise) to 70-90% (where every sentence reinforces something) - the cheapest way to make native content usable months early.

Where to get input

    Target-language subtitles on target-language video, always - captions produce large gains at every level. Milestone hours below the bar are Dreaming Spanish reference points and explicitly estimates, not evidence.
